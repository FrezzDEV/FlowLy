# FlowLy

FlowLy — music that flows the way you want it.

This repository is a Flutter music application.

## Current focus
- stable APK generation in GitHub Actions
- FlowLy branding and application identity
- safe Flutter/Dart baseline
- clean analysis configuration

### 🔴 Плеер — функциональность
- [ ] Проверить открытие полноэкранного плеера из любого горизонтального списка и с баннера на главной.
- [ ] Проверить, что один трек не открывает два экземпляра полноэкранного плеера.
- [ ] При открытом полном плеере не должны одновременно отображаться Main Bar и мини-плеер.
- [ ] Повторное открытие того же трека через баннер/список не должно оставлять старый мини-плеер поверх полного плеера.
- [ ] Проверить переход **мини-плеер → полный плеер** с анимацией появления снизу.
- [ ] Проверить возврат **полный плеер → мини-плеер** с анимацией сверху вниз; боковой анимации быть не должно.
- [ ] Проверить свайп сверху вниз: плеер **скрывается/сворачивается в мини-плеер, но музыка не закрывается и не останавливается**.
- [ ] В полном плеере кнопка **Назад** должна быть сверху слева.
- [ ] В полном плеере кнопка **три точки** должна быть сверху справа.
- [ ] Убрать кнопку `Открыть на весь экран`, когда пользователь уже находится в полном плеере.
- [ ] Убрать пять лишних кружков/временных элементов из интерфейса полного плеера.
- [ ] Убрать `Song/video` из интерфейса плеера.
- [ ] Убрать серую заливку у кнопок `Далее`, `Текст`, `Похожие`.
- [ ] Кнопка **Скачать** должна находиться справа.
- [ ] В блоке информации под баннером: название трека слева, ниже исполнитель, ниже ряд действий: **лайк / комментарии / скачать**.
- [ ] Лайк в плеере должен быть именно кнопкой лайка; не возвращать дизлайк на это место.
- [ ] Проверить открытие/закрытие меню по кнопке три точки.
- [ ] Проверить запуск, паузу, перемотку, переключение треков, предыдущий/следующий трек и повтор.
- [ ] Проверить корректную обработку недоступного/удалённого аудио: показывать ошибку, а не молчаливое отсутствие реакции.

### 🔴 Фон полного плеера
- [ ] Фон полного плеера должен использовать **обложку текущего трека**.
- [ ] Обложка должна масштабироваться на весь фон.
- [ ] Фон должен быть сильно размыт (`blur`) и затемнён/тонирован так, чтобы текст и элементы управления оставались читаемыми.
- [ ] Эффект должен работать при переключении между треками без необходимости перезапуска плеера.
- [ ] Поведение размытого фона должно соответствовать уже используемому эффекту в мини-плеере.

### 🔴 Уведомления / Android Media Player
- [ ] Проверить системное уведомление плеера в шторке Android.
- [ ] В уведомлении должны отображаться обложка, название трека и исполнитель.
- [ ] Проверить Play/Pause и переключение треков из уведомления.
- [ ] Проверить управление плеером после блокировки экрана.
- [ ] Проверить корректное восстановление состояния после сворачивания приложения.

### 🔴 Профиль
- [ ] Профиль должен быть компактным и соответствовать согласованному макету; не возвращать огромные размеры.
- [ ] Убрать `Premium` рядом с именем, если он не нужен в финальном дизайне.
- [ ] Не возвращать карандаш около аватара, если он был отключён в последней версии требований.
- [ ] Проверить загрузку/выбор аватара и сохранение выбранного изображения, если функция редактирования аватара включена.
- [ ] Проверить экран редактирования профиля.
- [ ] Проверить, что пункт `Аккаунт` в настройках открывает именно настройки редактирования профиля.
- [ ] В профиле под аватаром не должно быть отдельных пунктов `Настройки`, `Тема`, `Уведомления` — эти функции должны находиться в настройках приложения.

- [ ] Выполнить release-сборку AAB для Google Play.
- [ ] APK должен публиковаться как **отдельный `.apk` файл**, а не только внутри ZIP-архива.
- [ ] Установить APK на чистое устройство/эмулятор.

- [ ] Проверить отсутствие крашей после холодного запуска.
- [ ] Проверить release build непосредственно на физическом Android-устройстве перед публикацией.

# FlowLy

FlowLy — music that flows the way you want it.

This repository is now a clean Flutter application shell prepared for the next FlowLy milestones.

## Current focus
- stable APK generation in GitHub Actions
- FlowLy branding and application identity
- safe Flutter/Dart baseline
- clean analysis configuration

## ⚠️ ИЗМЕНИТЬ ПЕРЕД РЕЛИЗОМ

Перед публикацией релизной версии обязательно проверить и изменить следующее:

### 🔴 Убрать тестовые данные
- Удалить тестовый трек `Demo Player` из рекомендаций на главной.
- Удалить любые demo/mock данные, добавленные только для проверки плеера.
- Убедиться, что в рекомендациях отображаются только реальные треки/API-данные.

### 🔴 Проверить плеер
- Убрать временные тестовые ссылки на аудио.
- Проверить запуск, паузу, перемотку, переключение треков и открытие полного окна плеера.
- Проверить, что плеер корректно обрабатывает недоступный или удалённый трек.

### 🔴 Проверить профиль
- Удалить временные заглушки/тестовые данные профиля.
- Проверить загрузку и сохранение аватара.
- Проверить экран редактирования профиля и настройки аккаунта.

### 🔴 Проверить навигацию и UI
- Проверить Main Bar: `Главная`, `Поиск`, `Библиотека`, `Профиль`.
- Проверить повторное нажатие на активный раздел `Профиль`.
- Проверить отступы, размеры текста и иконок на разных разрешениях.
- Убедиться, что нигде не осталось временных UI-элементов, созданных для тестирования.

### 🔴 Проверить данные и backend
- Проверить API endpoints и production-конфигурацию.
- Удалить debug-логи и временные `print()`.
- Проверить обработку ошибок сети и пустых ответов API.
- Убедиться, что секреты, токены и ключи не находятся в репозитории.

### 🔴 Финальная проверка сборки
- Запустить `flutter analyze --no-fatal-infos --no-fatal-warnings`.
- Собрать release APK.
- Установить APK на чистое устройство/эмулятор.
- Проверить первый запуск, навигацию, поиск, библиотеку, профиль и плеер.
- Проверить отсутствие крашей после холодного запуска.

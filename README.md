# FlowLy

**FlowLy — музыка, которая течёт так, как удобно тебе.**

FlowLy — мобильное музыкальное приложение нового поколения. Цель проекта — дать пользователю не просто плеер, а персональное музыкальное пространство с чистым каталогом, умными рекомендациями, гибкими фильтрами и глубокой настройкой поведения приложения.

## Функционал FlowLy

### Музыка и воспроизведение

- Прослушивание треков, альбомов, плейлистов и артистов.
- Полноценное воспроизведение музыки.
- Очередь воспроизведения.
- Play / pause / next / previous.
- Перемотка и управление прогрессом трека.
- Повтор и перемешивание.
- Избранное.
- История прослушивания.
- Офлайн-режим.
- Мини-плеер и полноэкранный плеер.
- Управление воспроизведением из системных уведомлений.

### Поиск и каталог

- Поиск треков, артистов, альбомов и плейлистов.
- Поиск по жанрам.
- Поиск текстов песен.
- Определение и выбор разных версий одного трека.
- Приоритет оригинальных релизов.

### Фильтрация контента

Пользователь должен иметь возможность самостоятельно управлять тем, какой контент попадает в каталог и рекомендации:

- отключение ремиксов;
- отключение каверов;
- отключение пародий;
- отключение AI-generated треков и низкокачественного AI-контента;
- приоритет оригинальных версий;
- скрытие дубликатов;
- скрытие низкокачественных вариаций;
- возможность разрешать live и acoustic версии;
- режим «чистого каталога» только с оригинальными релизами.

### Рекомендации

- Персональные рекомендации на основе истории и предпочтений.
- Умная очистка рекомендаций от нежелательных версий.
- Mood-режимы: Focus, Chill, Night Drive, Sad, Workout, Nostalgia.
- FlowMix — автоматические миксы из любимых треков с учётом пользовательских фильтров.
- Рекомендации похожих треков при отсутствии точного совпадения при импорте.

### Плейлисты и медиатека

- Создание и удаление плейлистов.
- Добавление и удаление треков.
- Избранные треки.
- Альбомы.
- Скачанные треки.
- Недавно добавленные.
- История прослушивания.
- Изменение порядка треков в плейлисте и очереди.

### Перенос музыки

FlowLy должен поддерживать импорт пользовательской медиатеки из других музыкальных сервисов:

- плейлистов;
- избранных треков;
- альбомов;
- артистов;
- истории прослушивания;
- рекомендаций для похожих треков, если точного совпадения нет.

Источники импорта могут подключаться постепенно по мере развития backend-интеграций.

### Темы и персонализация

FlowLy должен позволять пользователю настраивать само поведение и оформление приложения:

- готовые темы;
- пользовательские темы;
- темы сообщества;
- сохранение пресетов;
- публикация пресетов;
- редактор тем;
- предпросмотр темы;
- настройка цветовых акцентов;
- прозрачность элементов;
- размер карточек и кнопок;
- стиль обложек;
- компактный или расширенный режим;
- включение и отключение анимаций.

### Сообщество тем

Отдельная часть экосистемы FlowLy должна позволять пользователям:

- загружать собственные темы;
- публиковать интерфейс-пакеты;
- ставить оценки оформлениям;
- скачивать популярные пресеты;
- создавать подборки стилей.

### Профиль слушателя

Профиль должен хранить и показывать:

- любимые жанры;
- любимых артистов;
- музыкальные привычки;
- статистику прослушивания;
- историю;
- пользовательские плейлисты;
- применённую тему и персональные настройки.

### Системные возможности

- Кэширование данных и обложек.
- Хранение пользовательских настроек.
- Устойчивое состояние плеера.
- Работа с сетью и обработка ошибок.
- Подготовка к авторизации и синхронизации между устройствами.
- Подготовка к полноценному backend API FlowLy.

## Приоритет разработки

### Этап 1 — основа

- Стабильный Flutter/Dart проект.
- Архитектура приложения.
- Музыкальный каталог и модели данных.
- Настоящий аудиоплеер.
- Очередь.
- Плейлисты.
- Избранное.
- История.

### Этап 2 — качество каталога

- Фильтры ремиксов, каверов, пародий и AI-контента.
- Оригинальные версии.
- Дубликаты и версии треков.
- Умные рекомендации.
- FlowMix.

### Этап 3 — персонализация

- Система тем.
- Редактор тем.
- Сохранение пресетов.
- Импорт и экспорт настроек.

### Этап 4 — экосистема

- Импорт медиатеки из других сервисов.
- Сообщество тем.
- Публикация и рейтинги пресетов.
- Профили пользователей.
- Синхронизация между устройствами.

### Этап 5 — дополнительные возможности

- Синхронизированные тексты песен.
- Совместные плейлисты.
- Режим вечеринки.
- Семейные профили.
- Рекомендации по времени суток.
- Интеграция с автомобилями и умными колонками.

## Важно

Этот репозиторий использует существующий Flutter-проект как техническую основу. Исходная логика и функциональность должны быть постепенно адаптированы под требования FlowLy. README описывает **целевой функционал**, а не точное состояние текущей реализации.
